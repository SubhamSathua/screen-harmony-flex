# Security Policy

## Supported Versions

The following versions of ScreenHarmony Flex are currently being supported with security updates:

| Version | Supported |
| ------- | --------- |
| 2.7.13  | Supported |
| 2.x     | Supported |

## Reporting a Vulnerability

If you find a security vulnerability, please **DO NOT** open a public issue. Publicly disclosing a vulnerability can put users at risk.

Instead, please report security vulnerabilities directly to the maintainer via GitHub Security Advisories or by reaching out through the repository contact channels:
- **Repository:** [https://github.com/SubhamSathua/screen-harmony-flex](https://github.com/SubhamSathua/screen-harmony-flex)
- **Profile:** [https://github.com/SubhamSathua](https://github.com/SubhamSathua)

We will acknowledge your report and attempt to fix the issue as soon as possible.

## Distribution & Malware Disclaimer

The author of this project only provides source code and official releases through authorized channels (this GitHub repository).

- **Official Builds:** Only releases published directly by the original maintainer on [https://github.com/SubhamSathua/screen-harmony-flex/releases](https://github.com/SubhamSathua/screen-harmony-flex/releases) are official ScreenHarmony Flex products.
- **Third-Party Distributions:** We are **not responsible** for versions of this software downloaded from other websites, forums, or third-party app stores.
- **Modified Versions:** If you download a version that has been modified or recompiled by someone else, you do so at your own risk.
